- `logo-16x16.svg`: Favicon estándar.
- `logo-32x32.svg`: Favicon HD.
- `logo-64x64.svg` / `logo-128x128.svg`: App Icons / Widgets.
- `logo-256x256.svg` / `logo-512x512.svg`: Profile Avatar / Social Media Preview.
- `logo-1024x1024.svg`: High Resolution Print & Display.
